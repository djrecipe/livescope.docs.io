Set-up Instructions

Android

  1. Download and install Android Studio from here
  2. Using Android Studio, install Android SDK to a non-default path, e.g. "_C:\AndroidSDK_"
  3. Download Android NDK 25.2.9519653 from here
  4. Place the contents of the NDK into the correct SDK subpath. For example "_C:\AndroidSDK\ndk\25.2.9519653_" (this folder will now contain sub-directories such as build, meta, etc.)
  5. Configure Visual Studio options to point to the correct Android SDK and NDK

Hardware-Specific Limitations

Android glGenBuffer

Typically I use NEW separate array element, color, normal and text buffers for EACH individual series displayed on a chart. However it seems that after a few series this will crash Android, and thus it is necessary to share more buffers (don't call glGenBuffer as often). See commit: ce2d4142c90585676a32f312fb97cb75e304c914

License Generation

  1. Generate a private key file (private.key) and public key file (public.key) via LiveScopeLicenseGenerator.exe -pk {password}
  2. Generate a license key LiveScopeLicenseGenerator.exe -trial {private_key_path} {password} {customer_name} {customer_email}
  3. Convert entire contents of license key to base64 string
  4. Now use this base64 string as your inline license!
